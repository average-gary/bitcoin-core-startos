# Bitcoin Core Testnet4 for StartOS

This repo packages [Bitcoin Core](https://bitcoin.org) for StartOS, configured to run on the Testnet4 network.

Testnet4 is the fourth iteration of Bitcoin's test blockchain, providing a safe environment for development and testing without risking real bitcoin.
